# 英硕模拟器

《英硕模拟器》是一款以英国一年制硕士生活为背景的手机端策略叙事游戏。玩家需要在有限行动点、资金和个人状态之间做选择，同时处理学业、社交与伦敦生活中的随机事件。

## 当前阶段

项目目前处于 **伦敦十月四周 Demo** 阶段，暂时只提供理工科人设，用于验证核心玩法、数值节奏、移动端交互和内容方向。长期计划是扩展为完整的 36 周免费版本。

## 已有内容

- 随机人设、家庭支持与基础属性
- 每周三个固定行动和四张机会卡
- 学业、资金、生命、精神、社交与 NPC 关系系统
- 履约、爽约、概率判定与专业重判
- 周结算、月度个性化总结和 36 周剧情预告
- 像素贴纸收藏、存档与移动端适配
